# Activation

Dictate is free during early access, and each Mac activates once with your email.

1. Press Activate in Browser in Dictate's window, in the menu or in Setup.
2. On the page that opens, enter your email. You get a code by email.
3. Enter the code, then press Open Dictate. Dictate opens on Setup.

Until a Mac is activated, Dictate doesn't record. The shortcuts and the agent server are off. The menu offers Activate in Browser in place of recording. About and updates still work.

The page has to be opened from Dictate: it carries a request only this Mac made, so a code from another request is refused and you press Activate in Browser again. A request left open stays good for a day.

Dictate keeps the result as one item in your login Keychain, so updates keep it. Deleting that item (see [Uninstall](./uninstall.md)) returns Dictate to a fresh install.

Once activated, About in Settings shows your activation ID. Send Feedback, in About or the menu bar menu, opens a feedback page in your browser that sends the ID with your message. The ID is made from your activation and cannot be used to activate anything.
